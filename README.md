# SHAHI AGRO FARM App

Responsive bilingual e-commerce starter for **SHAHI GRASS SILAGE** and **SHAHI PREMIUM GHEE**. Built with React + Vite and optional Supabase backend.

## Features included

- Responsive storefront inspired by the supplied SHAHI AGRO FARM screenshots
- English/Bangla language toggle
- Exactly two product families: grass silage and premium ghee (two size variants)
- Silage quantity rules: 20–400 packets; 50 kg per packet; ৳350 per packet
- Ghee variants: 900 g ৳1,450 and 200 g ৳800
- Cart, subtotal, area-based delivery fee, checkout, order reference, and order history in the current browser
- Payment-method choices: bKash, Nagad, Upay, Rocket, Cash on Delivery
- Manual transaction-ID field for prepaid orders
- Dedicated bilingual About Us page with official website, Facebook, Instagram, phone, WhatsApp, location, and courier partner links
- Order confirmation shows the 3–5 day delivery promise; no in-app order tracking or admin section is exposed to customers
- SQL schema with row-level security policies
- Original SVG placeholder illustrations, replaceable with supplied brand assets

## Important status / limits

This is a working **starter project**, not a deployed production service. Without Supabase configuration, it runs in local demo mode and saves orders only in the current browser. Local demo orders are not shared between devices.

The listed mobile-banking options use manual transaction verification. No payment gateway is activated by this project. To accept automated payments, register for the relevant merchant/payment gateway and implement its server-side payment initiation, callback verification, and reconciliation. Never trust a transaction ID supplied by a customer without checking it.

The app does not expose an order tracking form. Customer order history currently uses the current browser storage; if Supabase is configured, order submissions are also saved to the backend, but customer-specific cloud order history requires a secure authenticated or phone-verified endpoint before production. Do not make the orders table publicly readable.

## Android app (Capacitor)

This project is prepared to be packaged as an Android app using Capacitor. The Android APK is **not included yet**; building it requires Android Studio/Android SDK and downloading npm dependencies.

1. Install Node.js 20+ and Android Studio on a computer.
2. In this project folder run:
   ```bash
   npm install
   npm run build
   npx cap add android
   npx cap sync android
   npx cap open android
   ```
3. In Android Studio, wait for Gradle sync, then choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. For future web changes run `npm run cap:sync` before rebuilding in Android Studio.

The app ID is `com.shahiagrofarm.app`. The Android project folder is generated by `npx cap add android` on the build computer. A signed release APK/AAB requires your own signing key and testing.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
cp .env.example .env
npm run dev
```

Open the local URL Vite prints in the terminal.

## Build for deployment

```bash
npm run build
npm run preview
```

The production files are created in `dist/`. Upload the project to GitHub, then connect the repository to a static host such as Vercel or Netlify. Configure the same environment variables in the host dashboard.

## Supabase setup

1. Create a Supabase project.
2. Open **SQL Editor** and run `supabase/schema.sql`.
3. In project settings, copy the Project URL and publishable/anon key into `.env` as `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
4. Configure the anonymous order-insert policy in `supabase/schema.sql` and test that an order can be submitted.
5. Keep order reads private. This customer-facing build intentionally has no admin dashboard or in-app tracking.

**Never put the Supabase `service_role` key in this frontend app or in GitHub.**

## Production checklist

- Replace SVG product artwork with approved brand/product photography.
- Confirm delivery fees by service area with your delivery provider. Current starter defaults are Subarnachar ৳80, Noakhali Sadar/Maijdee ৳100, other Noakhali ৳130, outside Noakhali ৳160.
- Confirm phone and WhatsApp support are active.
- Add customer order ownership/authentication if customers need cross-device order history.
- If adding cloud order history in the future, implement a secure customer ownership or phone-verification mechanism; do not expose all orders publicly.
- Add real payment gateway integration and server-side verification before advertising automated online payments.
- Test mobile layout, checkout, order confirmation, payment reconciliation, and backups.
- Add privacy policy, terms, returns policy, and food/feed product details as appropriate.
